# user.js

This is a directory containing user.js files for Phoenix overrides/specialized
configs. If you want to use the override/specialized config in your profile,
simply copy and paste the corresponding `user.js`
file _(from the `userjs` directory)_ into your Firefox profile's directory.
The `user.js` file itself does not need to be updated,
as it will always pull the latest
configuration file locally from Phoenix's installation folder.
