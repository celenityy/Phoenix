# Policies

- `phoenix-unified.json` - These policies should be set **EVERYWHERE**.
- `phoenix-core.json` - These policies should be set everywhere,
**EXCEPT** for Thunderbird *(Useful for ex. IronFox)*.
- `phoenix-only.json` - These policies should be set everywhere,
**EXCEPT** for Android and Thunderbird *(Useful for ex. Dove)*.
- `phoenix-desktop.json` - These policies should be set everywhere,
**EXCEPT** for Android.
- `phoenix-linux-unified.json` - These policies should **ONLY** be set for GNU/Linux.
- `phoenix-only-linux.json` - These policies should **ONLY** be set for GNU/Linux,
but **NOT** for Thunderbird.
- `phoenix-osx-unified.json` - These policies should **ONLY** be set for macOS.
- `phoenix-only-osx.json` - These policies should **ONLY** be set for macOS,
but **NOT** for Thunderbird.
- `phoenix-windows-unified.json` - These policies should **ONLY** be set for Windows.
- `phoenix-only-windows.json` - These policies should **ONLY** be set for Windows,
but **NOT** for Thunderbird.
