# Policies

- `phoenix-core.json` - These policies should be set **EVERYWHERE**.
- `phoenix-no-android.json` - These policies should be set everywhere,
**EXCEPT** for Android.
- `phoenix-no-android-no-mail.json` - These policies should **ONLY** be set for
Firefox on desktop platforms.
- `phoenix-no-mail.json` - These policies should be set everywhere,
**EXCEPT** for Thunderbird *(Useful for ex. IronFox)*.
- `phoenix-osx.json` - These policies should **ONLY** be set for OS X.
