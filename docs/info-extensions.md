# ➕ Recommended Extensions

This page details a curated list of high quality extensions, that may or may not be useful to you, depending on your personal preference and use case. **Please note that it is strongly recommended to keep your installed extensions to a minimum; only get what you actually need/use**. Just because an extension is listed here doesn't necessarily mean you should use it, especially if you don't have a use for it.

For an extension to be added to this page, it **must** meet the following criteria:

* Be Signed by Mozilla
* Be Free and Open Source
* Provide legitimate value to end-users
* Must never sell data or track users in any way. Any data shared to 3rd parties must be done so for legitimate purposes and with user consent. Anonymous telemetry/analytics are acceptable, although not preferred, but there **must** be a way for the user to opt out of this telemetry if present.
* Have a solid upstanding & reputation
* Extensions listed on [AMO *(`addons.mozilla.org`)](https://addons.mozilla.org/)* are strongly preferred.
* Extensions [recommended by Mozilla](https://support.mozilla.org/kb/add-on-badges#w_recommended-extensions) are preferred.
